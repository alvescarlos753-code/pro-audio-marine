# PRO Áudio Marine - Versão 2 

Site premium estilo empresa grande, inspirado em layout náutico de luxo.

## Como usar
1. Extraia o ZIP.
2. Abra o arquivo `index.html` no navegador.
3. Para editar textos, abra `index.html`.
4. Para editar cores e visual, abra `style.css`.
5. Para trocar imagens, substitua os links Unsplash no `index.html` ou no `style.css`.
